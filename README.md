# Speech-to-Text using Hugging Face 
This project demonstrates a speech-to-text pipeline using **Wav2Vec2** from Hugging Face Transformers.

##  Tools
- Python
- Hugging Face Transformers
- PyTorch
- Librosa
- Google Colab
- 
##Goal
Convert audio input to text using pre-trained model

##Output Example
"I HAVE A DREAM THAT ONE DAY THIS NATION WILL RISE UP..."
